Ferrsphen maps QQ face IDs to Noto Emoji artwork using `noto-emoji-map.json`. The mapping changes presentation only. SVG posters and Lottie animations are downloaded from Google's CDN and cached locally. Lottie playback uses Velato with Vello CPU.
